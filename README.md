# Harsha's Assistant

A private desktop AI assistant designed to remember context, support daily decisions, and reduce the repeated work of explaining goals and preferences to an AI.

## Why it matters

Leaders lose time switching between tasks and rebuilding context. This project explores an assistant that keeps long-term memory, offers direct strategic feedback, and stays available from the desktop.

## Core capabilities

- Persistent memory for conversations, goals, and preferences
- Founder-focused decision support
- Global desktop shortcut and system-tray access
- Voice interaction and meeting awareness
- Local or hybrid AI model operation

## Technology

Electron, React, TypeScript, FastAPI, LangGraph, SQLite, ChromaDB, local speech models, and encrypted storage.

## Status

This repository is a Windows-focused beta. Review its implementation and security model carefully before storing sensitive business information.
